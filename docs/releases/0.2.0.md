# Page Debug Snapshot 0.2.0 (2026-10-22)

Zakres: epik **E0 — Fundament: repo, build, testy, higiena MV3 (Chrome + Firefox)**.
Licencja: MIT. Wydanie wewnętrzne — nic nie zostało wysłane do żadnego sklepu.

## Dla zgłaszającego
- Po kliknięciu „Zapisz paczkę” popup mówi po polsku, co się stało: zapisano plik (z jego nazwą), strona jest niedostępna, brak zgody na pliki lokalne, brak karty albo błąd. Nie pokazuje już „sukcesu”, gdy zrzut się nie udał.
- Na stronie z pliku z dysku (`file://`) popup wyjaśnia krok po kroku, jak włączyć „Zezwalaj na dostęp do adresów URL plików”.
- Rozszerzenie prosi o mniej: nie ma już dostępu do wszystkich stron naraz (`<all_urls>`), działa tylko na karcie, na której klikniesz.
- Działa też w Firefoksie (poprzednio tylko Chrome). Paczka rozszerzenia jest mała (ok. 14 KB).
- Instrukcja: `docs/INSTRUKCJA-ZGLASZAJACEGO.md`.

## Dla developera
- Dwa targety z jednej bazy: `npm run build` składa `dist/chrome` i `dist/firefox` z `src/manifest.base.json` + nakładek; `version` tylko w `manifest.base.json`.
- `npm run pack` — `dist/page-debug-snapshot-chrome-0.2.0.zip` (14 176 B) i `dist/page-debug-snapshot-firefox-0.2.0.zip` (14 279 B), deterministyczne.
- Komendy: `npm ci`, `npm run lint` (eslint + `web-ext lint`), `npm test` (215 testów vitest/jsdom), `npm run test:e2e` (13 testów Playwright, Chromium), `npm run icons`, `npm run check:history`.
- Pętla dev: `npm run dev:chrome` / `npm run dev:firefox` (opcjonalnie `PDS_CHROMIUM_BINARY`).
- Wstrzykiwanie przez `scripting.executeScript` (świat `MAIN`); usunięto `inject.js`. Schemat paczki bez zmian (`schemaVersion` 1.0.0).
- Repo: kod w `src/`, narzędzia w `scripts/`, testy w `tests/`; `package.json` bez `dependencies`.

## Uprawnienia
- Usunięte: `host_permissions` (`<all_urls>`), `web_accessible_resources`.
- Pozostały: `activeTab`, `scripting`. Nowych brak.
- Firefox: `data_collection_permissions: none`; `gecko.id` = GUID `{799eb178-df9a-41bb-9775-8fc8aff45926}`.

## Znane ograniczenia
- Chrome: gdy automatyczne pobieranie wielu plików jest zablokowane, popup może pokazać „Gotowe” bez pliku (naprawa: E1-T8, uprawnienie `downloads`).
- Paczka zawiera dane jawne: ciasteczka, storage, treść strony, wartości pól (poza `password`/`hidden`); po zrzucie zostaje `window.__PAGE_DEBUG_SNAPSHOT__` (redakcja i usunięcie globala: E3). Nie wysyłaj paczek z prawdziwymi danymi osobom nieupoważnionym.
- Firefox: dodatek tymczasowy znika po restarcie przeglądarki (podpis AMO: E5); ikona jest w panelu „Rozszerzenia”, nie na pasku.
- `web-ext lint`: 2 ostrzeżenia (`data_collection_permissions` vs `strict_min_version` 128) — dopuszczone.
- Dev: `npm audit` zgłasza 3 high w `web-ext` (tylko devDependency, poza paczką).

## Jak zainstalować 0.2.0
- Chrome: `npm ci && npm run build`, potem `chrome://extensions` → tryb dewelopera → „Załaduj rozpakowane” → `dist/chrome`.
- Firefox: `about:debugging#/runtime/this-firefox` → „Załaduj dodatek tymczasowy…” → `dist/firefox/manifest.json` (albo `npm run dev:firefox`).
- Szczegóły: `README.md` (Szybki start, Ręczne ładowanie), `docs/INSTRUKCJA-ZGLASZAJACEGO.md`.
- Aktualizacja z wcześniejszej wersji: usuń stare rozszerzenie, zbuduj i załaduj `dist/` ponownie.

4. E5 — grafiki sklepowe (small promo 440x280, zrzuty 1280x800) i teksty listingu PL/EN.

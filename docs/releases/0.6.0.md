# Page Debug Snapshot 0.6.0 (2026-10-27)

Zakres: epik **E4 — Wyjście: podsumowanie, przeglądarka paczki, przekazanie, dostęp dla agenta**.
`schemaVersion` bez zmian: **4** (konsument v4 z 0.5.0 czyta paczki 0.6.0). Licencja: MIT.
Wydanie wewnętrzne — nic nie zostało wysłane do żadnego sklepu.

## Dla zgłaszającego
- Po *Zapisz paczkę* popup pokazuje ekran **„Zapisano”**: nazwa pliku, przycisk „Pokaż plik” (otwiera folder z plikiem) i „Nowe nagranie”. Plik wysyłasz developerowi sam — wysyłki z popupu nie ma.
- Zdanie o zgodzie na przetwarzanie danych stoi nad przyciskiem „Nagrywaj” i jest widoczne bez przewijania.
- Redakcja haseł i tokenów jest dokładniejsza (klucze na początku tekstu, kody i bilety w adresach, argumenty konsoli); pola formularzy na zrzucie mają mniejszy margines maski (etykiety zostają czytelne).
- Brak nowych uprawnień — przeglądarka nie zapyta o nic dodatkowego.

## Dla developera
- **`summary.md`** ma stałą strukturę: środowisko, ostatnie kroki (z oznaczeniem kroku przed pierwszym błędem), grupy błędów, nieudane zapytania, CWV, najwolniejsze zasoby, ciasteczka, prywatność, uwagi (≤ 16 KB, ≤ 200 linii). Ten sam tekst w rozszerzeniu, viewerze i MCP. Przewodnik: `docs/JAK-CZYTAC-PACZKE.md`.
- **Viewer** `dist/page-debug-viewer-0.6.0.html` (117 949 B, artefakt `npm run pack`, nie ma go w zipach rozszerzenia): jeden plik, `file://`, offline, CSP z hashami, dane renderowane wyłącznie jako tekst. Zakładki: Podsumowanie, Kroki, Błędy, Sieć, Konsola, CWV, DOM, Storage. Czyta paczki v1–v4; dla v1–v3 baner o braku redakcji.
- **Serwer MCP** `mcp/` (v0.6.0, stdio, bez zależności npm, tylko odczyt, poza zipami): `list_snapshots`, `get_summary`, `get_errors`, `get_network`, `get_vitals`, `get_steps`, `diff_snapshots`; jeden katalog paczek na serwer (argument lub `PDS_SNAPSHOTS_DIR`), limit odpowiedzi 25 000 znaków. Konfiguracja: `mcp/README.md`.
- **Konfiguracja developerska**: `npm run build|dev:* -- --config <plik>` (wzór: `pds.config.example.json`) albo polityka `storage.managed` (Chrome: `managed-schema.json`; Firefox: `policies.json`). Wyłączyć można `email`, `phone`, `html-structure`; popup i `summary.md` ujawniają wyłączone reguły. `npm run pack` bez `--config` daje artefakty bez sufiksu `-devconfig` (tylko takie do sklepów).
- **Redakcja `rulesVersion: 2`**, notatki o zrzucie w `notes`, `srcdoc` ramek zastąpiony znacznikiem, maskowanie w MAIN odporne na podmienione iteratory strony.
- `RECORDER_VERSION` = `version` w manifeście = 0.6.0 (bundle przegenerowane `npm run gen`); wersje w `package.json`, `package-lock.json`, `mcp/package.json` zgodne.
- Testy: e2e Chromium 128/128 (dwa przebiegi, przed podbiciem wersji); jednostkowe i lint — patrz CHANGELOG i `docs/epics/E4/state.md`. Review: approve-with-fixes (wszystkie findings zamknięte), QA: PASS z uwagami.
- `npm run pack`: chrome 188 773 B (36 plików), firefox 188 641 B (35 plików); zip Chrome zawiera `managed-schema.json`, Firefox nie.

## Uprawnienia
- Nowe: brak. Usunięte: brak (`activeTab`, `scripting`, `storage`, `downloads`; `optional_host_permissions` bez zmian). Manifest Chrome dostaje klucz `storage.managed_schema` (nie jest uprawnieniem).

## Znane ograniczenia
- Frazy-hasła złożone z samych słów pod `session:`/`key:`/`auth:` w cudzysłowie nie są maskowane (PB-2); podgląd JSON długiego wpisu konsoli nie zamaskuje `{"value":…,"name":"password"}`.
- Nieutwardzone: podmienione iteratory `Map`/`Set`/`String`, `%ArrayIteratorPrototype%.next` i metody tablic na stronie; telefony w tekście kroków nie są maskowane.
- `downloads.show` nie sygnalizuje usunięcia pliku; ekran „Zapisano” sprawdza plik przez `downloads.search`.
- Klucz diffu statusów w MCP to metoda + `pathname` (bez hosta).
- Do weryfikacji ręcznej (checklista w `docs/epics/E4/qa-report.md`, „Checklista ręcznego QA dla użytkownika”): Eksplorator Windows („Pokaż plik”), prawdziwy klient MCP, Firefox i Edge, polityki `storage.managed` w obu przeglądarkach (Firefox: spike S3).
- Dystrybucja do sklepów (polityka prywatności, Limited Use, `docs/store`) — epik E5.

## Jak zaktualizować
- Chrome: `npm ci && npm run build`, `chrome://extensions` → „Załaduj rozpakowane” → `dist/chrome` (albo rozpakuj `dist/page-debug-snapshot-chrome-0.6.0.zip`).
- Firefox: `about:debugging#/runtime/this-firefox` → „Załaduj dodatek tymczasowy…” → `dist/firefox/manifest.json`.
- Z 0.5.0: załaduj ponownie; zakończ trwające nagranie przed aktualizacją. Paczki v4 bez zmian. Zipy `*-0.5.0.zip` zawierały kod E4 pod starą wersją — nie używaj ich.

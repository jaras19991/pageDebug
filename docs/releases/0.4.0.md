# Page Debug Snapshot 0.4.0 (2026-10-23)

Zakres: epik **E2 — Kompletność danych: kroki, CWV, statusy, zrzut** (schemat paczki v3).
Licencja: MIT. Wydanie wewnętrzne — nic nie zostało wysłane do żadnego sklepu.

## Dla zgłaszającego
- Paczka zawiera teraz **kroki**, które wykonałeś (kliknięcia, wpisywanie w pola, wysłanie formularza, Enter/Escape/Tab, przejścia między stronami). Wpisanego tekstu nie zapisujemy — tylko jego długość.
- Przy „Zapisz paczkę” rozszerzenie robi **zrzut widocznej części karty**. Uwaga: zrzut pokazuje wszystko, co jest na ekranie, także dane wpisane w pola (np. e-mail, numer karty); hasła są ukryte. Wyślij plik tylko developerowi.
- Paczka mówi, czy strona była wolna (LCP, CLS, INP, TTFB, FCP) i co ją spowalniało.
- Lista „Do pliku trafią:” w popupie jest rozszerzona o kroki, fragmenty odpowiedzi serwera i zrzut; komunikat „Zapisano…” jest widoczny nad sekcjami.
- Brak nowych uprawnień — przeglądarka nie zapyta o nic dodatkowego.

## Dla developera
- Schemat **v3** (`schemaVersion: 3`, zmiana łamiąca): `overview`, `steps[]`, `vitals[]` z atrybucją i `longTasks`, `network[]` z zasobami strony i statusami, `responseBodyPreview` dla odpowiedzi ≥ 400, `screenshots[]` + `attachments`, `frame`, `Error.cause`, nowe `limits`/`truncated`. Opis i migracja v2 → v3: `docs/snapshot-schema.md`; fixture `tests/fixtures/snapshots/v3.json`, walidator `tests/helpers/snapshot-validator.js`.
- Statusy z Resource Timing (bez `webRequest`, decyzja D2); `fetch` `no-cors` to `status: null` + `statusUnavailable: "cross-origin"`.
- `RECORDER_VERSION` = `version` w manifeście = 0.4.0 (bundle przegenerowane `npm run gen`). Protokół tło ↔ strona w wersji 2.
- Testy: 994 jednostkowych, 73 e2e (Chromium, 2,1 min, wyrocznia `web-vitals` w granicach 10 %); Firefox 158 — QA ręczne (FQ-1..12). `npm run pack`: chrome 93 209 B, firefox 93 308 B, po 21 plików.

## Uprawnienia
- Nowe: brak. Usunięte: brak. Bez `webRequest`, `tabs`, `cookies`, `host_permissions`. Zrzut używa `activeTab`.

## Znane ograniczenia
- **Dane nadal niezredagowane** (redakcja: E3): ciasteczka, storage, nagłówki, treść żądań i fragmenty odpowiedzi trafiają do pliku wprost; zrzut może pokazywać wpisane dane. Przełącznik „Dołącz zrzut” i maskowanie pól na obrazie: E3.
- Wyborcza.pl: ok. 77% zasobów sieciowych bez statusu (CDN, cross-origin bez `Timing-Allow-Origin`).
- Do weryfikacji ręcznej: uśpienie komputera (AC-2.2), aktualizacja 0.3.0 → 0.4.0 z trwającym nagraniem (AC-1.6), klik myszą w popup w Firefoksie + HiDPI, AC-7.3 stoperem.
- Firefox: INP dostępny; `input type=file` zapisuje długość „C:\fakepath\…” (E3). Maskowanie wzorców sekretów: `sessid`, `Basic <b64>`, pary XML (E3).
- `npm audit`: 3 high (node-forge ← adbkit ← web-ext; devDependency, nie trafia do paczki); fix = downgrade web-ext, decyzja użytkownika.
- Obraz zrzutu jest w `attachments` (viewer: E4).

## Jak zaktualizować
- Chrome: `npm ci && npm run build`, `chrome://extensions` → „Załaduj rozpakowane” → `dist/chrome` (albo rozpakuj `dist/page-debug-snapshot-chrome-0.4.0.zip`).
- Firefox: `about:debugging#/runtime/this-firefox` → „Załaduj dodatek tymczasowy…” → `dist/firefox/manifest.json`.
- Z 0.3.0: załaduj ponownie; zakończ trwające nagranie przed aktualizacją. Paczki v2 mają inną strukturę — migracja w `docs/snapshot-schema.md`.

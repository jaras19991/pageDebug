# Page Debug Snapshot 0.5.0 (2026-10-26)

Zakres: epik **E3 — Prywatność i rozmiar paczki** (schemat paczki v4, zmiana łamiąca).
Licencja: MIT. Wydanie wewnętrzne — nic nie zostało wysłane do żadnego sklepu.

## Dla zgłaszającego
- *Zapisz paczkę* tworzy teraz **jeden plik zip** (`snapshot-<strona>-<data>.zip`), który otwiera się zwykłym dwuklikiem. W środku jest podsumowanie po polsku, dane i zrzut.
- **Hasła, tokeny i wartości ciasteczek są usuwane z pliku automatycznie.** E-mail i telefon w danych strony są domyślnie zamazywane. Treść wpisana w pola nie trafia do paczki (tylko jej długość).
- Przy *Zapisz paczkę* jest przełącznik „Dołącz zrzut ekranu” (domyślnie włączony). Pola formularzy na zrzucie są zakryte. **Uwaga:** formularze osadzone z innych serwisów (np. płatność, logowanie w ramce) mogą być widoczne — gdy takie są na stronie, przełącznik startuje wyłączony.
- Plik jest mały (do 2 MB). Gdy strona jest bardzo ciężka, część danych jest przycinana, a plik mówi, co i ile.
- Brak nowych uprawnień — przeglądarka nie zapyta o nic dodatkowego.

## Dla developera
- Schemat **v4** (`schemaVersion: 4`): kontener zip (`snapshot.json`, `summary.md`, `screenshot.jpg`), klucz `redaction` (`rulesVersion`, `disabledRules`, `masked`), znaczniki `[redacted:<reguła>]`, `storage.cookies[]` z `valueHash`, `dom.structure` zamiast `dom.html.outerHTML`, długości zamiast wartości pól/`alt`/`title`, `limits.packageBytes` i nowe flagi `truncated.*`. Migracja v3 → v4: `docs/snapshot-schema.md`; fixture `tests/fixtures/snapshots/v4.json`.
- Redakcja w tle przed zapisem (`src/lib/redact*.js`), budżet rozmiaru (`budget.js`), writer zip (`zip.js`), SHA-256 w czystym JS. `devOptions: { disabledRules }` w `exportPackage` — kontrakt bez źródła w UI (E4).
- `RECORDER_VERSION` = `version` w manifeście = 0.5.0 (bundle przegenerowane `npm run gen`). `PROTOCOL = 3`.
- Testy: 1370 jednostkowych (64 pliki), e2e Chromium 105/105 (ostatni pełny przebieg po iteracji 3; iteracja 4: testy prywatności 30/30); `npm run lint` bez błędów (2 ostrzeżenia web-ext o `strict_min_version`/`data_collection_permissions`, bez zmian względem E2). `npm audit --omit=dev`: 0.
- `npm run pack`: chrome 162 413 B, firefox 162 511 B, po 30 plików (po 466 KB rozpakowane).
- Uwaga: testy wydajności redakcji w `export.test.js`/`redact-rules.test.js` bywają czerwone przy pełnym równoległym przebiegu na WSL (limity czasowe); osobno i w ponownym pełnym przebiegu zielone.

## Uprawnienia
- Nowe: brak. Usunięte: brak (`activeTab`, `scripting`, `storage`, `downloads`; `optional_host_permissions` bez zmian).

## Znane ograniczenia
- **Ramki z innych originów nie są zakrywane na zrzucie** (decyzja PB-1 B).
- Redakcja regułowa ma luki i fałszywie dodatnie: N7, N8, N12, N15, `console.log('Your password is', x)`, `&amp;quot;`, podwójne kodowanie procentowe, base64 < 32 znaków, `AKIA…` bez słowa-klucza; „123 456 789 zł” bywa maskowane jako telefon; UUID w nagłówku bywa maskowane jako karta. Lista w README „Znane ograniczenia”; część w backlogu E4.
- `valueHash` ciasteczka bez soli; notatka „turned off by the reporter” pojawia się także przy wyłączeniu przez popup; notatka o cięciu logów może zaniżać liczbę (F-2).
- Do weryfikacji ręcznej: Eksplorator Windows 11 i Archiwizator macOS, mignięcie przy zrzucie, pinch-zoom fizycznym gestem, zamknięty shadow DOM w Firefoksie, stoper developera (60 s). Firefox 158: tylko smoke QA.

## Jak zaktualizować
- Chrome: `npm ci && npm run build`, `chrome://extensions` → „Załaduj rozpakowane” → `dist/chrome` (albo rozpakuj `dist/page-debug-snapshot-chrome-0.5.0.zip`).
- Firefox: `about:debugging#/runtime/this-firefox` → „Załaduj dodatek tymczasowy…” → `dist/firefox/manifest.json`.
- Z 0.4.0: załaduj ponownie; zakończ trwające nagranie przed aktualizacją. Paczki v3 (JSON) mają inną strukturę — migracja w `docs/snapshot-schema.md`.
